# Security Policy

## Supported Versions

Kami mendukung versi terbaru dari aplikasi ini untuk pembaruan keamanan.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Jika Anda menemukan celah keamanan, mohon **JANGAN** membuat issue publik. 
Silakan hubungi tim IT KBM Group atau kirim email ke admin@kbm.group.

Laporan akan ditinjau dan divalidasi dalam waktu 2x24 jam.
